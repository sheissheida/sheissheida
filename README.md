# Hi, I'm Sheida

I am an undergraduate Chemical Engineering student at SRBIAU in Tehran, though you will usually find me writing Python or building numerical simulations.

I focus on translating mass and heat transfer, thermodynamics, and phase equilibria into reproducible code. I’m particularly interested in **computational biomedical engineering**, where transport phenomena, numerical modeling, and heat transfer can be applied to complex biological systems.

### 🚧 Currently Building

* **LabData Assistant** *(In Development)*
  A reproducible Python pipeline for taking raw CSV/Excel laboratory data through inspection, cleaning, analysis, and visualization. The project is designed to preserve the original raw data while generating useful scientific summaries and reports.

* **PhaseForge — VLE & Flash Calculation Studio** *(Planned)*
  An interactive binary vapor–liquid equilibrium and flash-calculation simulator. I’m starting with Antoine equation parameters, Raoult’s law, and bubble/dew points, with plans to integrate more advanced activity-coefficient models.
